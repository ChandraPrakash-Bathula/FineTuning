# Interactive Fine-Tuning Laboratory

A four-part lesson built on eleven real fine-tuning runs of
`Qwen/Qwen2.5-7B-Instruct` on WikiSQL: why fine-tuning is needed, what full
fine-tuning costs, how LoRA reduces trainable parameters, how QLoRA reduces
memory, and a playground that replays each measured experiment.

Everything here reads recorded artifacts — measured metrics, real loss curves,
and 1,000 held-out questions answered by every variant. Live inference is not
part of this Space; see the Docker variant for that.
